# Tic Tac Toe

A simple two-player Tic Tac Toe game playable in the browser.

## How to Play

1. Open `index.html` in your browser
2. Players take turns clicking cells — X goes first
3. First to get 3 in a row (horizontal, vertical, or diagonal) wins
4. Click **New Game** to reset the board

## Features

- Two-player mode (X vs O on the same screen)
- Win detection with highlighted winning cells
- Draw detection
- Score tracking across games

## Run

```bash
open index.html
```

No dependencies or build steps required — just a single HTML file.
